# 축의대 관리 시스템

예식 현장에서 신랑측·신부측 축의대의 방명록, 축의금, 식권과 특이사항을 관리하는 단일 HTML 프로그램입니다. 인터넷 없이 각 PC에서 접수하고, JSON 파일을 주고받아 기록을 병합할 수 있습니다.

- **버전:** `20261029`
- **저작권:** © 2026 해저씨
- **블로그·이용허락 문의:** https://blog.naver.com/benzcrasher
- **이용 조건:** [LICENSE.txt](LICENSE.txt)

## 시작하기

1. `축의대.html`을 사용할 PC의 폴더에 저장합니다.
2. 파일을 브라우저로 엽니다. 별도 설치, 빌드, 서버 실행은 필요하지 않습니다.
3. 처음 표시되는 **안내** 화면에서 오른쪽 **설정** 탭으로 이동합니다.
4. 이 PC의 담당 구분을 **신랑측 PC**, **신부측 PC**, **공용 PC** 중에서 선택합니다.
5. 예식 정보와 필요한 시설 안내·식권 수량을 설정하고 접수를 시작합니다.

개발 과정에서 데스크톱 Chrome으로 동작을 검증했습니다. 실제 사용할 PC와 브라우저에서 행사 전에 오프라인 실행과 저장·복구를 확인하세요. 전체화면은 브라우저의 지원 및 허용 여부에 따라 동작합니다.

## 화면 구성

왼쪽에는 현장 업무 메뉴, 오른쪽에는 정산·관리 메뉴가 배치되어 있습니다.

| 메뉴 | 주요 기능 |
| --- | --- |
| 안내 | 식사·주차·시설 답변, 돌발상황 대처법, 역할·주의사항을 표시하는 현장 답변판 |
| 방명록 | 하객 접수, 금액 확인, 식권 지급 기록, 검색·필터, 수정·삭제, 10명 단위 페이지 이동 |
| 식권 | 측별 초기·차용·지급·잔여 수량과 소진율 확인 |
| 정산 | 측별 인원·확인 금액·평균·식권 집계와 시간별 특이사항 기록 |
| 양식 | 입력된 방명록, 공백 방명록, 정산서 인쇄 및 PDF 저장 |
| 설정 | 예식·시설·식권·담당자·안내 편집, 파일 백업·병합, 전체 초기화 |

탭 오른쪽의 **전체화면** 버튼을 누르면 최상단 헤더를 숨겨 작업 공간을 넓힙니다. **전체화면 종료** 버튼이나 `Esc`로 돌아올 수 있습니다.

## 행사 전 설정

- **예식 정보:** 신랑·신부 이름, 예식 일자·시간, 장소를 입력합니다. 축의대 도착 목표는 예식 **1시간 전**으로 자동 계산됩니다. 직접 수정하면 그 시간이 유지되며, 자동 설정 버튼으로 되돌릴 수 있습니다. 자정을 넘겨 계산되는 경우 전날 도착으로 안내합니다.
- **하객 안내:** 식사 장소·시간, 소인 기준, ATM, 대기실, 답례품 정보를 입력합니다.
- **주차:** 공통 무료 시간·도장 위치를 정하고, 건물 및 외부 제휴 주차장을 여러 곳 등록할 수 있습니다. 각 주차장의 이름·위치·무료 시간·도장 위치를 지정하며, 개별 이용 조건을 비우면 공통 설정을 사용합니다.
- **식권 준비:** 신랑측·신부측 대인·소인 초기 수량을 입력합니다.
- **담당자:** A는 하객 응대·식권 지급, B는 장부 정리·현금 보관 담당으로 입력합니다.
- **안내 편집:** 기본 안내를 수정·삭제하거나 새 안내를 추가합니다. 기본 시설 안내는 설정을 따라가지만, 직접 수정한 항목은 편집한 내용으로 고정됩니다.

설정은 입력 시 브라우저에 저장됩니다. PC 담당 구분은 해당 브라우저에 따로 저장되며, 다른 PC의 행사 파일을 불러와도 유지됩니다.

## 방명록 접수와 금액 확인

입력 순서는 **구분 → 성함 → 식권 → 축의금 → 비고**입니다.

- 담당 PC에 맞는 측이 자동 선택됩니다. 공용 PC에서는 접수할 측을 선택합니다.
- 식권은 직접 입력하거나 `+`·`−` 버튼으로 **1장씩** 조절합니다.
- 축의금은 **원 단위**로 직접 입력하거나 `+`·`−` 버튼으로 **1만원씩** 조절합니다. 금액 바로 선택 버튼도 사용할 수 있습니다.
- 성함과 식권부터 기록하고, 축의금은 비워둔 채 접수할 수 있습니다.
- 금액을 비우면 **미확인**, 숫자 `0`을 직접 입력하면 **확인된 0원**으로 구분합니다.
- 미확인 기록은 목록에서 강조되며, 전용 필터 또는 **순서대로 확인**으로 금액만 연속 입력할 수 있습니다.

목록은 **10명씩** 표시합니다. 검색·필터를 바꾸면 첫 페이지로 이동하며, 새 하객을 등록하면 해당 기록이 있는 페이지를 표시합니다. 하단의 **조회 합계**는 현재 페이지가 아닌 검색·필터 결과 전체를 집계합니다.

정산 금액과 금액 평균은 확인된 기록을 기준으로 봅니다. 최종 정산 전에 미확인 기록이 남아 있는지 확인하세요. 이전 파일에서 금액이 0이고 확인 상태 정보가 없는 기록은 미확인으로 분류됩니다.

## 현장 안내 사용

기본 화면에서 시설 답변과 돌발상황의 첫 행동을 바로 읽을 수 있습니다. 카드를 누르면 전체 내용을 크게 표시하며, 긴 안내는 페이지로 나눕니다. 작은 화면이나 안내가 많은 경우에는 분류·페이지를 전환해 확인합니다.

검색에는 시설 이름뿐 아니라 “차를 가져왔어요”, “돈을 돌려달래요” 같은 일상 표현도 사용할 수 있습니다. 등록된 내용과 미리 정의한 유사 표현을 검색하는 기능으로, 외부 AI 서비스에 질문을 전송하지 않습니다.

## 특이사항 빠른 기록

어느 탭에서든 오른쪽 아래 **특이사항** 버튼 또는 `Alt+M`으로 기록 패널을 엽니다.

1. 현재 접수 내용을 유지한 채 메모를 작성합니다.
2. **기록하고 돌아가기** 또는 `Ctrl+Enter`로 저장합니다.
3. 기록 후 원래 작업의 입력란과 커서 위치로 돌아갑니다.

작성 중인 새 메모는 임시 저장되어 패널을 닫거나 브라우저를 다시 열어도 복구할 수 있습니다. 저장된 기록에는 **입력 날짜·시각과 담당 PC 구분**을 남깁니다. 시각은 PC의 시간을 바탕으로 **한국 시간(Asia/Seoul)**으로 표시합니다.

각 기록의 **수정** 버튼으로 내용을 바꿀 수 있습니다. 입력 시각은 유지하고 수정 시각을 별도로 표시합니다. **삭제**는 확인 후 실행됩니다. 접수 초안과 작성 중인 새 메모는 기존 기록의 수정·삭제와 별개로 유지됩니다.

특이사항은 빠른 기록 패널과 정산 화면에서 확인·수정·삭제할 수 있으며, 정산서 인쇄와 JSON 내보내기에도 포함됩니다.

## 신랑측·신부측 PC의 데이터 병합

현재 버전은 **실시간 자동 연동을 지원하지 않습니다.** 각 PC가 독립적으로 저장하고, 파일로 병합합니다.

1. 두 PC에 같은 버전을 준비하고 각자의 담당 구분을 설정합니다.
2. 각 PC에서 **내보내기**로 JSON을 저장하고, 어느 측의 파일인지 구분해 보관합니다.
3. 한 PC로 파일을 전달한 뒤 **불러오기**를 누릅니다.
4. 필요한 항목을 체크하고, 방명록은 상대 측을 대상으로 **기존 기록에 병합**을 선택합니다.
5. 특이사항을 합치려면 **특이사항 기록**도 별도로 체크합니다.
6. 인원·금액·식권·특이사항을 확인한 뒤 통합본을 다시 내보냅니다.

불러오기는 예식·시설 정보, 담당자, 식권, 안내사항, 방명록, 특이사항 등을 선택해 적용합니다. 대상 측 선택은 방명록·담당자·식권에 적용하며, 예식·안내·메모는 공통 항목입니다. 이전 버전의 정산 메모도 파일 호환을 위해 불러올 수 있습니다.

- 방명록 중복은 **기록 ID**로 판단합니다. 같은 이름으로 따로 접수한 기록은 자동 통합하지 않습니다.
- 같은 ID의 방명록 내용이 다르면 현재 PC 기록 또는 파일 기록 중 어느 쪽을 사용할지 선택합니다.
- **선택한 측 전체 교체**는 해당 측의 기존 방명록을 교체하므로 병합과 구분해 사용하세요.
- 방명록의 삭제 이력을 적용하려면 **파일에 포함된 삭제 기록 반영**을 선택합니다.
- 특이사항은 최신 수정 시각을 기준으로 병합하며, 삭제 이력도 함께 반영합니다. 이전 파일을 다시 불러와도 오래된 내용으로 되돌리거나 삭제된 기록을 다시 추가하지 않도록 처리합니다.
- 불러오기 직전 상태는 자동 보관합니다. 설정 → **백업·PC 병합 → 직전 불러오기 되돌리기**로 복구할 수 있습니다. 이 기능은 마지막 불러오기 이전 상태로 돌아가므로 이후 입력한 내용도 함께 되돌아갑니다.

## 저장·백업과 오프라인 운영

현재 프로그램은 HTML 안에 스타일과 스크립트를 포함하며, 실행에 외부 서버나 라이브러리 다운로드가 필요하지 않습니다. 블로그 링크를 여는 경우에는 인터넷이 필요합니다.

운영 데이터는 **현재 브라우저의 localStorage**에 저장됩니다. HTML 파일 자체에 기록되는 방식이나 서버 자동 백업 방식이 아닙니다.

- 행사 전에는 실제 사용할 PC에서 인터넷을 끄고 입력 → 종료 → 재실행 → JSON 불러오기를 점검하세요.
- 행사 중에는 같은 파일 경로, 브라우저, 브라우저 프로필을 유지하세요. 파일 주소에서의 저장 동작은 브라우저에 따라 달라질 수 있습니다.
- 브라우저 저장 데이터 삭제, 시크릿 모드 종료, 기기 변경 시 기존 기록에 접근하지 못할 수 있습니다.
- 행사 중간과 종료 직후 JSON을 내보내고, PC 고장에 대비해 별도 저장 매체에도 보관하세요.
- HTML 파일을 복사하는 것만으로 접수 데이터가 이동하지 않습니다. 데이터는 JSON으로 내보내고 불러와야 합니다.
- 하객 성함·축의금·메모가 포함된 JSON은 개인 보관용입니다. 공개 GitHub 저장소나 공개 배포 파일에 포함하지 마세요.

GitHub Pages에 게시해도 PC 간 동기화나 서버 백업이 생기지는 않습니다. 현재 버전에는 서비스 워커 기반 오프라인 캐시가 없어, 호스팅 주소의 오프라인 재접속·새로고침을 보장하지 않습니다. 현장에서는 미리 내려받은 파일로 운영할 수 있습니다. 호스팅 주소와 로컬 파일의 브라우저 저장소는 별개이므로 전환할 때도 JSON을 사용하세요.

## 인쇄와 전체 초기화

**양식** 탭에서 입력된 방명록, 공백 방명록, 정산서를 선택하고 **인쇄 / PDF 저장**을 누릅니다. PDF는 브라우저 인쇄 창에서 저장 대상으로 선택합니다. 금액 미확인 상태와 특이사항의 입력·수정 시각도 관련 출력에 반영됩니다.

전체 초기화는 **설정 → 백업·PC 병합 → 전체 초기화**에서 실행합니다. 삭제 범위를 확인한 뒤 다음 단계에서 `초기화`를 직접 입력해야 실행됩니다.

초기화 대상은 이 PC의 예식·시설·주차·식권·담당자 설정, 안내 편집, 방명록, 특이사항과 임시 메모, PC 담당 구분, 불러오기 복구 기록입니다. 다른 PC의 데이터와 이미 내려받은 JSON 파일은 삭제하지 않습니다. 초기화 전에 필요한 기록을 내보내세요.

## 단축키

| 단축키 | 동작 |
| --- | --- |
| 접수 입력란에서 `Enter` | 다음 입력란으로 이동, 마지막 비고 입력란에서는 접수 등록 |
| 접수 입력 중 `Ctrl+Enter` | 접수 등록 또는 수정 저장 |
| `Alt+M` | 특이사항 패널 열기·닫기 |
| 특이사항 입력·수정 중 `Ctrl+Enter` | 기록 저장 또는 수정 저장 |
| 안내 화면에서 `/` | 안내 검색창으로 이동. 다른 입력란에 입력 중일 때는 적용하지 않음 |
| `Esc` | 열린 대화상자 또는 특이사항 패널 닫기. 전체화면에서는 브라우저 동작에 따라 전체화면 종료 |

저장 단축키는 macOS의 `Command+Enter`도 지원합니다.
